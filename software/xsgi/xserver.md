# The X server (`Xsgi`): function reference

Sources: `usr/gfx/arch/GENERIC/Xsgi` (6.5.30m), the SGI X server with the Kona X module and GLX module loaded into it ([kona-ddx.md](kona-ddx.md), [x-server-glx.md](x-server-glx.md)). It is a build of the X Consortium sample server with SGI's device layer, and most of its symbols are the standard routines of that server. Roles are **inferred** from the names, which follow the sample server's conventions (`Proc*` for request handlers, `S*` for their byte-swapped forms, subsystem prefixes for extensions). A name is listed under the first group whose prefix matches; names the neighbouring documents already cover in detail are not repeated. The groups carry nothing about the Kona pipe beyond the `ddx*`, `rrm*`, `dbc*` and `glx*` glue.
