# Stored published sources

Full copies of the published patents, papers, technical reports, manuals, datasheets and web pages that [../published-sources.md](published-sources.md) cites for InfiniteReality, InfiniteReality2, InfiniteReality3 and InfiniteReality4. They are third-party documents kept here so a reader does not depend on a link that may vanish. Each entry in published-sources.md gives the in-repo path and the SHA-256 of its copy.

Layout: `patents/` by US patent number; `papers/` for conference and journal papers and slide decks; `reports/` for SGI technical reports and white papers; `manuals/` for SGI manuals, named by document number (the hardware developer handbook keeps its title); `specs/` for SGI datasheets, product guides, specification sheets and web pages.

The `sgi-docs` submodule holds only six IRIS GL manuals (programming guides, the reference manual and the GL-to-OpenGL porting guide) and a format note, none about InfiniteReality hardware, so every InfiniteReality manual, datasheet and report is stored here.

Each copy is the file as fetched from the URL below, checked against its SHA-256. A copy that was not on its original host any more comes from the Wayback Machine capture named in the URL.
