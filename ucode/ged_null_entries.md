**Established** (the words). The loop at 0x003-0x005 (`dist.s` lines 13-15) and the loop at 0x006-0x008 (`dist.s` lines 18-20) are the same three words: a load of r69 with geometry-engine slot 176, `mgebi_NullCommand`, a transfer back to that load, and a no-op. Neither fetches nor releases, so a command that lands on one is consumed by the distributor without reaching an engine. Which loop an entry holds is read from table B itself.

**Inferred** (where each index comes from). The columns "formed by" and "loaded states" apply the index rule of [How an entry is chosen](ged.md#how-an-entry-is-chosen): index = 8 x A[r48] + 4 x state + j, with j = 0 for a vertex, 1 material, 2 `HP_END` (the end token) and 3 `HP_SWAPTMESH` (the swap token), and in the idle class the index is the token entry number k. Every class whose 64-entry block covers the index is listed as class:state, separated by spaces (no class block covers 0x1e8-0x1ff, where the slot is read as index mod 4); all of them share the token slot j, since every block starts at a multiple of 8. A state counts as loaded when some word of that class's module loads it into r49 (the idle reset value 0x1d excluded). For idle entries the last column counts the geometry-form host tokens whose command number has that k; attribute tokens such as colour and normal reach the vertex record without a program step, so a null loop there is the expected entry. The effect column follows: an entry that a loaded state or a geometry token can select swallows that token; one that nothing selects is a spare slot.
