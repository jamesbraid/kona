# Stored published sources

Full copies of the published patents, papers, technical reports, manuals and white papers that [../published-sources.md](../published-sources.md) cites for InfiniteReality and InfiniteReality2. They are third-party documents kept here so a reader does not depend on a link that may vanish. Each entry in published-sources.md gives the in-repo path, the SHA-256 and the library path of its copy.

Layout: `patents/` by US patent number; `papers/` for conference and journal papers and slide decks; `reports/` for SGI technical reports and white papers; `manuals/` for SGI manuals, named by document number.

Documents that the `sgi-docs` submodule already holds (the IRIS GL manuals) are not repeated; cite `sgi-docs/` for those.

Each copy is the file as fetched from the URL below, checked against its SHA-256. The library path is where the same file sits in the document library the copies came from; a copy that was not on its original host any more comes from the Wayback Machine capture named in the URL.
