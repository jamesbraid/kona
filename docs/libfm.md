# The font-manager library (`libfm.so`): function reference

Sources: `usr/lib32/libfm.so` (6.5.30m N32). The IRIX font manager is the library that IrisGL and OpenGL programs use for text: it reads bitmap and outline fonts, scales them and hands out glyph metrics and bitmaps. It is ordinary application-level code with no graphics-board access, and it is here only because the Kona tools and the X module link it. Roles are **inferred** from the names; much of the file-reading and font-directory code carries the names of the X sample server's font library, renamed with a `__fm_` prefix.
