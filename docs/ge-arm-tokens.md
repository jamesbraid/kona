# ARM-run host tokens read one by one

Host tokens whose map word names an ARM function run that function on the ARM. Each row gives the handler's address, how many instructions the function has, how many payload reads the scan found, and what the handler does. The handler addresses and counts are **established** (`ucode/arm1_handlers.tsv`, read from the ARM image); the effect column is **inferred** from reading each handler in `ucode/arm1.s`. The ARM keeps a zero in r8, so `[r8 + offset]` is an absolute context address. The engine ports are the descriptor port at r9 + 0x400, the select port at r9 + 0x474 or 0x438, the operand port at r9 + 0x840 and the data port at r9 + 0x8c0; a handler starts an engine routine by storing its address from the table `gepc` to a port.
